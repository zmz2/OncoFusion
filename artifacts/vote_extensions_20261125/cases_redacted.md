# 课堂案例（脱敏与释义）

以下均为真实模型运行的结果摘要。未公开病人身份、病例编号、私密提示与完整原文；原文位置以 PMID 追溯。中文段落是编辑者的释义，不是模型逐字输出，也不构成临床验证。

## 案例一：专业选票补足关系范围

**批次：** D-CIViC 开发样本的补充复核。  
**来源：** PMID 30980071。  
**主张释义：**主张涉及 ROS1 重排非小细胞肺癌中的 crizotinib 关系，并带有研究未验证的额外人群限定。原文摘录为保护版权省略，需直接查看原文确认研究对象和范围。

| 角色/系统 | 判断 |
|---|---|
| 单 Agent B0 | NEI |
| Literature | REVISIONS |
| Genomics | REVISIONS |
| Drug | REVISIONS |
| Pathology | SUPPORTS |
| 专业初始投票 | REVISIONS，3/4 有效票 |
| 仲裁 | 未触发：最高票占比正好为 0.75；触发条件是严格小于 0.75 |
| 参考标签 | REVISIONS |

**讲解重点：**该案例中，文献、分子和药物视角都关注主张是否超出研究覆盖范围，三票形成有效多数；病理角色给出相反意见。单 Agent 的 NEI 与专业票池不同。这个例子展示了专业选票如何提供互补检查角度，不能据此推断总体准确率必然提高。

## 案例二：实际触发仲裁，但未纠正标签

**批次：** 新鲜 CIViC 开发样本 E05a。  
**来源：** PMID 16834459。  
**主张释义：**主张将 MPL W476M 与特定嗜酸性粒细胞相关髓系/淋巴肿瘤语境相连；给定文章讨论的是 MPL W515L 的致癌功能及骨髓增殖性疾病语境。此释义概括了研究对象差异，不是原文引述。

| 角色/阶段 | 判断 |
|---|---|
| Literature | REVISIONS |
| Genomics | NEI |
| Pathology | NEI |
| 初始等权票 | NEI，2/3 有效票，最高票占比 0.667 |
| 仲裁触发 | 是：最高票占比低于 0.75 |
| 仲裁执行 | 完成 1 次；模型认为给定证据不足以评价主张，返回 NEI |
| 仲裁后标签 | NEI，未变化 |
| 参考标签 | REVISIONS |

**讲解重点：**仲裁器实际核对了来源中的变异和疾病语境，但最终选择 NEI，没有把证据与主张的关系差异转成 REVISIONS。因此，“触发且成功完成仲裁”不等于“纠错成功”。这是开发样本中的失败案例，完整计入准确率。

## 使用边界

两例只用于解释真实系统行为。第一例来自开发集补充样本；第二例也来自开发批次。它们不是独立测试集，也不能替代主实验统计。公开版本不含可复制的原文段落；释义仅帮助课堂理解，研究结论应以数据许可范围内的原文和汇总结果为准。
