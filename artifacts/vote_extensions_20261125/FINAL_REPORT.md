# OncoFusion vote-v1 补充实验报告

**报告日期：** 2026-11-25  
**主任务：** MTBBench 病例证据整合；CIViC-Fact 作为补充核验任务。  
**模型：** 千问 3.6 35B-A3B（API 标识 `hc-qwen38-27b-fp8`）。  
**冻结方法：** vote-v1；本轮未改角色、提示、证据预处理、平票或仲裁规则，也未改网页和 PPT。

## 主要结论

在排除 13 个历史上用于调试或方法选择的患者来源组后，MTB 独立来源隔离确认集包含 85 题、19 位患者。V3 正确 55/85（64.71%），B0 正确 48/85（56.47%），差值 **+8.24 个百分点**。按患者组进行 2,000 次 bootstrap（seed 0）的 95% 区间为 **+1.12 至 +16.09 个百分点**。V3 完成率 98.82%，B0 为 91.76%。这是本轮最有力的结果；样本只覆盖 19 个患者组，仍需按预先冻结的样本边界解释。

在双方都有有效答案的 77 题中，V3 相对 B0 改对 6 题、改错 1 题；另外 3 题由 B0 失败转为 V3 正确，1 题由 B0 正确转为 V3 失败。V3 的 4 次仲裁全部完成，改动 2 个标签且两例都改对。标签分布的多数类参考为 A 类 43/85（50.59%）。

30 题开发比较未显示跨任务一致优势：MTB 上 P-K 和 G-K 都为 60.00%；CIViC 上 G-K 为 86.67%，P-K 和 V3 为 83.33%。因此，不把开发集的小样本结果概括成两个任务上都优于单 Agent。CIViC117 只作为已记录的来源隔离补充结果，不称为本轮新跑的官方完整测试集。

## 冻结方法与数据

- B0 是当前 `b0_common_single` 通用单 Agent；G-K 是通用角色投票；P-K 是适用专业角色的独立投票；V3 在 P-K 初始票池后执行选择性语义仲裁。
- 适用专家读取同一份给定证据包；角色提示限定检查重点。专家票等权，不按模型自报置信度加权。Decision 汇总选票并按当前规则触发仲裁。
- 仲裁仅在最高票占比严格小于 0.75，或第一、第二名票差占比严格小于 0.25 时触发。仲裁失败保留初始有效票。所有失败保留在分母。
- 固定单例上限：B0 最多 3 次调用，投票池最多 12 次，仲裁最多 3 次；单例最多 260,000 token。没有全批次调用或 token 上限。所有实际模型请求共用 20 路全局并发上限。
- 数据指纹、标签来源、样本名单哈希、逐实验身份和设置见 [冻结配置](FROZEN_PROTOCOL.json)、[来源登记](SOURCE_REGISTER.json) 与 [实验协议](PROTOCOL.md)。原始输入、患者编号、完整提示和轨迹留在服务器。

## 证据缺失稳健性：E04

每个条件 20 题。R0 是 E05a 中同一批病例的未修改证据结果复用；R1–R4 只改变证据可见内容。V3 全部从相同 P-K 专家票派生，没有重复生成专家票。

| 条件 | 证据变化 | B0 | P-K 无仲裁 | V3 | V3 仲裁 / 标签变化 |
|---|---|---:|---:|---:|---|
| R0 | 原始证据，同病例基线 | 12/20（60%） | 13/20（65%） | 13/20（65%） | 2 触发，2 完成，0 改标签 |
| R1 | 移除基因/分子资料及重复分子内容 | 9/20（45%） | 11/20（55%） | 12/20（60%） | 3 触发、3 完成；1 改对 |
| R2 | 移除病理资料及重复病理内容 | 10/20（50%） | 15/20（75%） | 15/20（75%） | 3 触发、2 完成、1 失败；未改标签 |
| R3 | 确定性移除约 25% 临床事件行 | 10/20（50%） | 12/20（60%） | 13/20（65%） | 2 触发、2 完成；1 改对 |
| R4 | 确定性遮蔽约 25% 证据片段 | 13/20（65%） | 13/20（65%） | 14/20（70%） | 1 触发、1 完成；1 改对 |

E04 共 160/160 个基线病例执行：134 完整、14 降级、12 失败；失败留在分母。80/80 个 V3 派生病例均有输出：9 次触发仲裁、8 次完成、1 次失败；改标签 3 例且均改对。V3 派生增加 21 次真实 API 调用。该稳健性子集较小，R2 的点估计上升也说明这一固定样本不能被解读为证据删除的因果效应。逐条件证据删减计数见 [证据变更清单](missing_evidence_manifest.json)，指标见 [稳健性表](tables/robustness_summary.csv)、[逐类表](tables/robustness_per_class.csv) 和 [配对表](tables/robustness_paired.csv)。

## 其余机制与诊断结果

- **角色消融：**历史 MTB43 中，移除 Literature 或 Timeline 各少 1 个正确答案（−2.33 个百分点）；移除 Genomics 或 Pathology 没有改变总准确率。CIViC117 中，移除 Literature 少 2 题、移除 Pathology 少 1 题、移除 Genomics 多 1 题；Drug 只在 82 题适用且总准确率不变。所有差异来自既有票池的离线重聚合。
- **专家互补：**严格“只有该角色答对、其他有效角色均未答对”的 MTB 病例中，Literature、Pathology、Timeline 各有 1 例，Genomics 为 0；CIViC 中 Literature 2 例、Pathology 1 例、Drug 1 例、Genomics 0。独占正确例可见互补信息，但不足以证明任何单个角色带来稳定增益。
- **成员数：**共同 K=4 子集上，MTB n=36 时 k=1/2/3/4 的预期准确率为 56.25%/60.65%/58.33%/58.33%；CIViC n=82 时为 86.89%/88.21%/88.41%/89.02%。k=1 是随机单专家，不是 B0；这项结果由已保存票池枚举子集计算，没有新增 API 调用。
- **输入长度：**预先定义的 short/medium/long 组中，MTB n=15/14/14，B0 准确率 40.0%/35.7%/57.1%，V3 为 53.3%/57.1%/78.6%；CIViC 每组 39 条，B0 为 84.6%/76.9%/94.9%，V3 为 84.6%/79.5%/97.4%。这是分组关联，不作长文档因果结论，分组和成本见 [长度表](tables/length_summary.csv)。
- **证据位置：**MTB 前/中/后每组 8 题，P-K/V3 均为 3/8；B0 为 2/8、3/8、3/8。CIViC 每组 4 题，P-K/V3 均 4/4，B0 在末尾组为 3/4 且有 1 次失败。样本很小，见 [位置表](tables/position_summary.csv)。
- **仲裁阈值：**MTB D30 中从 0.50/0.60 到 1.00 阈值及 always-arbitrate 均未改变准确率；always-arbitrate 有 3 次失败。CIViC D30 也未观察到标签变化。各阈值调用成本见 [阈值表](tables/threshold_results.csv)。
- **提示机制消融：**75 个目标角色成员有 4 个成员级失败，但没有对应的整例票池失败；最终消融逻辑调用 115 次，其中 104 次为新 API 发送、11 条复用此前审计输出。角色变化对已聚合答案大多被票池吸收；详情见 [提示消融表](tables/prompt_ablation_summary.csv)。
- **引用核查：**历史 MTB12 例共 92 个引用位置，92/92 偏移准确；其中发现 1 条泛化预后陈述缺乏支持，但不是完整的逐主张核对。历史 CIViC 原始轨迹缺失，未作语义结论。D-CIViC 12 篇文章、24 个答案有 30/30 个引用位置准确；单次 AI 辅助语义审阅分类为支持 10、部分支持 14、不支持 0，未经临床专家裁定。见 [引用审计摘要](tables/citation_review_summary.csv) 和 [审阅规则](citation_review_rubric.md)。

## 执行异常与清理

E04 最后 6 条 V3 派生曾有一次错误启动，因未载入真实 API 环境而落到本地 `lexical-simulator-v1`。该输出没有计入任何成绩或 API 用量；它原样留档后，同一批 6 条从已保存的真实 P-K 选票重新派生并使用冻结模型运行。有效结果的所有批次均核验为 `hc-qwen38-27b-fp8`。异常记录见 [execution_exceptions.json](execution_exceptions.json)。

完成聚合和校验后，删除本轮 `results/v1/vote_extensions_20261125/` 原始病例轨迹、请求/响应日志和临时派生输出。聚合表、脱敏案例、配置指纹、执行账本、绘图和个别展示案例保留在本目录；删除文件数与字节数见 [清理清单](cleanup_manifest.json)。
