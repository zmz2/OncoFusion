# Expanded test run: MTBBench 140 and CIViC-Fact 150

Generated by `scripts/make_extended_plan.py` on 2026-11-08. Both plans use seed 0 and one
execution per case and arm: 580 case executions in total.

## Sampling

- MTBBench: every 140 case in the frozen test split.
- CIViC-Fact: 150 frozen test cases, selected by SHA-256 from `sampling_seed=20261108`.
  The subset contains exactly 50 SUPPORTS, 50 REVISIONS and 50 NEI cases. No article contributes
  more than three cases.
- Labels and article groups are used only to freeze the sample. They are not included in model
  payloads.

## Arms

- `v1_class`: live seven-agent `v1_class` profile with claims-v1.
- `single_tools_shared_evidence`: one analysis agent plus final decision. It shares the same
  model, evidence selection, fragment citation resolution, finding limit, output cap, schema
  repair policy and 260,000-token budget. Claim identifiers and the specialist verifier chain are
  absent because there is no multi-agent handoff to address.

Both plans run LangGraph and retain the same retrieval, isolation, source deduplication and
external-verification settings. Results must be stored in new directories and failed or incomplete
cases must remain in the denominator.

The paired calibration plans use one MTB case per label and one CIViC case per verification label,
with distinct case subjects. They contain ten executions across both arms and must finish before
the formal 580-execution workload is launched.
