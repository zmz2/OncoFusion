# 架构与实现范围

## 第一版架构

首版以 `profiles.v1_config()` 为明确入口：LangGraph固定专家工作流，共享结构化证据、六个分析节点和一个最终决策节点；同模型、串行、零自动补证。ToolUniverse快照在运行前按公开查询审核并冻结，标准基准不联网补资料。原native执行器与可回查配置保留为比较/回归。详见V1_REVIEW.md。

## 证据生命周期

`CaseInput → 强制可见性过滤 → 专业预处理 → 专业分析 → 检索后证据 → 核验 → 最多一次回查 → DecisionOutput`。

运行首先生成只含当前 `stage` 与 `as_of_day` 可见文档的深拷贝。默认角色顺序为 Timeline、Genomics、Pathology、Drug、Literature、Verifier、Decision。检索前角色只看到病例资料；文献经过当前检索工具后进入工作集。专业预处理信号会基于已检索工作集更新，原始全文仍可逐字引用。

状态保存在一个显式 Python 状态机中。每个角色有独立职责提示、输入、结构化输出和工具信号；同一基础模型用于隔离架构变量。角色委派只改变专业提示，保留信息和工具。`fixed_five` 只调用基础五角色；`single_iterative` 使用六次通用分析加最终回答，匹配 Full 的基础调用数。

## Agent 与可消融机制

| Agent | 内部机制 | 实现细节 |
|---|---|---|
| Genomics | 变异归一化 | p.Val600Glu / p.V600E → V600E；来源文本的变异位置与原文并存；仅支持蛋白替换，复杂 HGVS 保留原值 |
| Pathology | 疾病语境 | 显式疾病实体匹配、癌种/组织学/标本等命名字段提取；保留原文范围 |
| Drug | 方向区分 | sensitivity/resistance/mixed/unknown 词法特征；混合方向保留，模型结合原文解释 |
| Literature | 检索重排 | 同一个 BM25 候选池内按查询实体覆盖重排；属于透明词法重排 |
| Timeline | 结构化时间 | 按来源阶段与可选日期排列，历史与当前可见性由运行边界决定 |
| Verifier | 外部原文核验 | 引用原文检查主张；reflection 消融只看已有证据摘要与先前引用 |
| Decision | 来源去重 | 对相同来源/文本与重复证据记录去重后整合 |

变异提及最多保留 200 条、病理显式字段最多 100 条，限制会出现在工具信号中；原始已选文档继续保留。通路活性、致病性、疗效均需额外证据，字符串归一化本身仅处理表述。

## 共享证据与审计

Finding 包含 statement、relation、Citation。引用使用原文字符偏移 `[start,end)`；中文和 Unicode 按 Python 字符索引，前端直接高亮时应注意 JavaScript UTF-16 与 Unicode code point 的差异。只提供 quote 时，后端要求它在文档中唯一出现并定位；重复短句需要模型给精确偏移。

自动完整性检查确认“引用真实存在”。“引用语义支持主张”由真实 Verifier 与独立人工盲审评价。两类指标分别报告。

每次运行记录：代码/输入/配置/供应商指纹、当前可见来源、每角色工具信号、模型调用起止、输出、检索排名、回查、已知 token、HTTP 重试次数和终态。日志是可复现的显式数据流记录。

## 预算与故障

模型调用、工具调用、token 分别限额。预检以 UTF-8 字节计数作为保守输入预留，再加最大输出，实际消耗使用供应商 usage。它是统一工程限额，正式成本曲线还应报告实际 token；不同模型 tokenizer 需另行校准。

Provider 对网络超时、429、5xx 有界重试；4xx 配置错误显式返回。返回截断、非法 JSON、虚假引用、无效任务标签终止该样本。可单独启用 `schema_repair`，修复调用同样计入预算。失败与预算耗尽都计入评测分母。

## 后端

FastAPI + SQLite WAL + 单 ASGI 进程线程池；默认 2 个 worker、最多 32 个未完成任务。病例存储为不可变快照；来源 ID 与持久化 UUID 分开。队列满返回 429；取消只支持 queued；启动时将遗留 queued/running 标为 interrupted，防止重复计费。数据库目录默认 0700，文件默认 0600。

Web 层与 Engine 通过 Pydantic 边界交互。后续分布式队列可以替换调度层，算法结果结构保持稳定。当前部署按一个可信研究团队的单用户服务设计；多租户身份与访问隔离应在公网业务化前单独完成。

## 可选外部工具

`tools.py` 提供 PubMed 搜索/摘要、Ensembl VEP 和本地快照缓存，已使用 HTTP 模拟测试。默认 benchmark 使用冻结材料；公共工具的网络调用与正式测试分开。研究者可以将已审核的公共检索结果转换为 Document，明确标注来源、许可和可见阶段后上传。新加语料的实验使用单独协议，与原始给定证据任务分别报告。

## 上游复用版

`workflow.py` 以同一节点闭包支持native和真实LangGraph StateGraph；只把已执行节点名存入图状态，病例、预算与轨迹沿用Engine执行上下文，因此当前图不提供checkpoint恢复或并行执行。`agent_design.py` 为七角色提供有来源的工作清单；`upstream_tools.py` 隔离地调用实际ToolUniverse SDK，生成审核后源快照。新增三机制开关独立于运行库开关；旧预设保持不变。详细设计和复用层级见 AGENT_REUSE_AUDIT。
